## 描述

chars: **811** / limit 4000

평문. 마크다운 기호 없음.

```
KORA 是一款为来韩国旅行的人打造的地铁指南 App。
只要选好出发站和目的站，就能看到换乘、经过站数、预计时间，以及该坐哪个方向的列车，直接按照列车上显示的“开往○○”告诉你。乘车时它会跟踪你所在的车站，快到站时提醒你下车。

【自动找到出发站】
用 GPS 查找最近的车站，也可以手动选择。选好的车站下次打开 App 时依然记得。

【路线与乘车方向】
显示换乘、站数和预计时间，并用列车上的“开往○○”标识告诉你该坐哪一班。末班车快到时会提前提醒。

【用相机确认方向】
把相机对准站台指示牌或列车终点站显示屏，就能马上判断方向是否正确。文字识别完全在 iPhone 上完成。

【随时知道自己在哪】
结合首尔实时到站信息、GPS、加速度计检测的发车与停车，以及车内广播识别来跟踪当前车站，还会告诉你哪一侧开门。

【下车提醒】
快到站时提示“请准备下车”，到站时提示“请立即下车”，并伴有振动。进度图上会显示列车图标和目的站图钉。

【锁定屏幕与灵动岛】
乘车途中，通过实时活动无需解锁手机就能查看行程进度。

【五种语言】
站名同时以韩语、日语（片假名）、英语和中文显示。整个 App 可在韩语、日语、英语、简体中文、繁体中文之间切换，默认跟随手机语言。

【支持地区】
首尔都市圈（首尔、京畿、仁川，含 GTX-A、机场铁路、新盆唐线和轻轨）、釜山、大邱、光州、大田，共约 930 个车站。可用选站画面的地区标签切换城市。

【离线也能用】
路线在设备上计算，没有网络也能查询。只有实时到站信息需要联网。

【重视隐私】
无需注册账号，没有广告和 App 内购买。定位、相机和广播识别都在设备上处理，不会保存或上传。我们只收集用于改进 App 的匿名使用统计。

相机、麦克风、语音识别和运动权限都是可选的。即使不允许，也可以手动选择车站并使用路线导航。

联系我们：mizzking75@gmail.com
```
