```
KORA 是專為來韓國旅遊的人設計的地鐵指南 App。
只要選好出發站和目的地，就會顯示轉乘、經過站數、預估時間，以及該搭哪個方向的列車，直接照列車上顯示的「往○○」告訴你。搭車時會持續追蹤你目前所在的車站，快到站時提醒你下車。

【自動找到出發站】
用 GPS 找出最近的車站，也可以自己選擇。選好的車站下次開啟 App 時還會記得。

【路線與搭乘方向】
顯示轉乘、站數和預估時間，並用列車上的「往○○」標示告訴你該搭哪一班。末班車時間接近時也會提前提醒。

【用相機確認方向】
把相機對準月台指標或列車的終點站顯示，就能馬上判斷方向對不對。文字辨識完全在 iPhone 上進行。

【隨時掌握目前位置】
結合首爾即時到站資訊、GPS、加速度計偵測的發車與停車，以及車廂廣播辨識來追蹤目前車站，還會告訴你哪一側開門。

【下車提醒】
快到站時提示「請準備下車」，到站時提示「請立即下車」，並搭配震動。進度圖上會顯示列車圖示和目的地圖釘。

【鎖定畫面與動態島】
搭車時透過即時動態，不必解鎖手機也能查看行程進度。

【五種語言】
站名會同時以韓文、日文（片假名）、英文和中文顯示。整個 App 可以在韓文、日文、英文、簡體中文、繁體中文之間切換，預設跟隨手機語言。

【支援地區】
首爾都會區（首爾、京畿、仁川，包含 GTX-A、機場鐵路、新盆唐線與輕軌）、釜山、大邱、光州、大田，共約 930 個車站。可以用選站畫面的地區標籤切換城市。

【離線也能用】
路線在裝置上計算，沒有網路也能查詢。只有即時到站資訊需要連網。

【重視你的隱私】
不需要註冊帳號，沒有廣告和 App 內購買。定位、相機和廣播辨識都在裝置上處理，不會儲存或上傳。我們只蒐集用於改善 App 的匿名使用統計。

相機、麥克風、語音辨識和動作權限都是選用的。就算不允許，也可以手動選擇車站並使用路線導航。

聯絡我們：mizzking75@gmail.com
```
