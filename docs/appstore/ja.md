## 概要

chars: **1097** / limit 4000

평문. 마크다운 기호 없음.

```
KORA は、韓国を旅するすべての人のための地下鉄ガイドアプリです。
出発駅と到着駅を選ぶだけで、乗り換え、駅数、所要時間の目安、そしてどちら方面の電車に乗ればいいかを、電車の行先表示「○○行き」そのままの形で案内します。乗車中は今どの駅かを追いかけ、降りるタイミングでお知らせします。

【出発駅はおまかせ】
GPS で最寄り駅を探すか、自分で選べます。選んだ駅は次にアプリを開いたときも覚えています。

【ルートと乗る方向】
乗り換え、駅数、所要時間の目安に加えて、乗るべき電車を「○○行き」の表示で示します。終電が近いときは事前にお知らせします。

【カメラで方向チェック】
ホームの案内板や電車の行先表示にカメラを向けると、乗ろうとしている方向が正しいかどうかをすぐに判定します。文字認識はすべて iPhone の中で行います。

【今どこにいるか正確に】
ソウルのリアルタイム到着情報、GPS、加速度センサーによる発車・停車の検知、車内アナウンスの認識を組み合わせて現在の駅を追跡します。アナウンスから、どちら側のドアが開くかもお知らせします。

【降車のお知らせ】
降りる駅が近づくと「そろそろ降車の準備」、到着すると「今降りてください」を振動でお知らせします。路線の進行図には電車アイコンと到着駅のピンが表示されます。

【ロック画面と Dynamic Island】
乗車中はライブアクティビティで、iPhone を開かなくても進み具合を確認できます。

【5つの言語】
駅名を韓国語、日本語（カタカナ）、英語、中国語で並べて表示します。アプリ全体は韓国語、日本語、英語、簡体字中国語、繁体字中国語から選べて、最初は iPhone の言語設定に合わせます。

【対応エリア】
ソウル首都圏（ソウル・京畿・仁川。GTX-A、空港鉄道、新盆唐線、軽電鉄を含む）、釜山、大邱、光州、大田の約930駅に対応。駅選択画面の地域チップで都市を切り替えられます。

【オフラインでも】
ルートは端末内で計算するので、インターネットがなくても検索できます。ネットワークを使うのはリアルタイム到着情報だけです。

【プライバシーを大切に】
アカウント登録、広告、アプリ内課金はありません。位置情報、カメラ、アナウンス認識はすべて端末内で処理し、保存も送信もしません。アプリ改善のための匿名の利用統計だけを収集しています。

カメラ、マイク、音声認識、モーションの許可はすべて任意です。許可しなくても、駅を自分で選べばルート案内を使えます。

お問い合わせ：mizzking75@gmail.com
```

## 키워드 메모
