プライバシーポリシー

施行日：2026年9月19日 ・ アプリ バージョン 1.0.5 以降に適用

本ポリシーは、KORA 開発者（Leeo、以下「開発者」）が提供する iOS アプリ「KORA 韓国ナビ」（以下「本アプリ」）が 情報をどのように扱うかを説明するものです。扱う情報はできるだけ少なく、端末の中にとどめることを基本方針としています。

ひと目でわかる概要

  • 会員登録やログインはありません。氏名、電話番号、メールアドレスなど、あなたを直接特定できる情報は収集しません。
  • 開発者が運営するサーバーはありません。アプリの設定は端末内にだけ保存されます。
  • 位置情報、カメラ、マイク・音声認識、モーションのデータは端末内だけで処理し、保存も外部への送信もしません。
  • アプリ改善のため、Google Analytics for Firebase で匿名の利用統計を収集します。広告、広告識別子（IDFA）、他社アプリをまたいだトラッキングは使用しません。

1. 取り扱う情報と取得方法

a. 端末内にだけ保存される情報

次回起動時に前回の状態を再現するため、以下の情報を端末内のアプリ領域（UserDefaults）に保存します。開発者や第三者に送信されることはありません。

  • 選択した現在駅（出発駅）と到着駅
  • 表示言語の設定
  • 駅選択画面で選んだ地域

b. 端末内だけで処理し、保存も送信もしない情報

情報目的取り扱い
位置情報（アプリ使用中のみ）最寄り駅の検索、乗車中の現在位置の推定座標は端末内の計算にのみ使い、保存も、どのサーバーへの送信もしません。
カメラ映像ホームの案内板や電車の行先表示の読み取りApple の Vision による文字認識で端末内で処理し、映像を保存・送信しません。
マイク音声と音声認識車内アナウンスから駅名と開くドアの側を認識端末内の音声認識だけを使います（サーバーでの認識は使いません）。音声を録音・保存・送信しません。
モーション（加速度センサー）電車の発車・停車の検知端末内だけで処理します。
ライブアクティビティロック画面と Dynamic Island に乗車の進み具合を表示端末内での表示だけで、外部には送信しません。

c. 自動的に収集される利用統計（Google Analytics for Firebase）

本アプリを使うと、Google Analytics for Firebase が次の情報を自動的に収集します。

  • アプリインスタンス ID（インストールごとにランダムに作られる識別子）
  • 初回起動（first_open）、セッション開始（session_start）、画面表示などの利用イベント
  • アプリのバージョン、端末の機種、OS のバージョン、端末の言語
  • IP アドレスから推定した国・地域（IP アドレス自体は開発者に提供されません）

これらの情報であなた個人を特定することはできず、開発者がほかの情報と組み合わせて特定することもありません。 広告識別子（IDFA）は収集せず、App Tracking Transparency の許可も求めません。広告や、他社のアプリ・ウェブサイトをまたいだトラッキングには使用しません。

d. リアルタイム地下鉄到着情報の取得

乗車中の現在駅を補正するため、ソウル・オープンデータ広場（ソウル特別市、data.seoul.go.kr）のリアルタイム地下鉄到着情報 API から到着情報を取得します。 送信するのは駅名だけで、あなたを特定する情報は含まれません。 ただしインターネット通信の性質上、接続元の IP アドレスがソウル特別市のサーバーに届く場合があり、同市の方針に従って取り扱われます。

2. 利用目的

  • ルート案内、現在駅の追跡、降車のお知らせなど、本アプリの機能の提供
  • 選んだ駅と言語を覚えて、次回起動時にそのまま表示するため
  • 利用状況の把握、不具合の修正、機能改善のための統計分析

上記以外の目的（広告、マーケティング、プロファイリング）には使用しません。

3. 保存期間

  • 端末内に保存される情報：本アプリを削除すると一緒に削除されます。iCloud 同期は使用しません（iPhone 全体のバックアップには端末データとして含まれる場合があります）。
  • 端末内だけで処理する情報：処理後ただちに破棄し、保存しません。
  • 利用統計：Google Analytics のデータ保持設定（2か月または14か月）に従い、期間を過ぎると自動的に削除されます。個人を特定できない集計データは、その後も残る場合があります。

4. 第三者への提供

法令に基づく場合を除き、あなたの個人情報を第三者に提供することはありません。

5. 業務委託と国外への移転

利用統計の分析のため、次のとおり情報の処理を委託しており、その過程で情報が韓国国外に移転されます。

委託先Google LLC（Google Analytics for Firebase）
移転先の国アメリカ合衆国（Google が運営する世界各地のデータセンターを含む）
移転する情報1-c の利用統計（アプリインスタンス ID、利用イベント、アプリのバージョン、端末の機種、OS のバージョン、端末の言語、IP から推定した国・地域）
時期と方法アプリの使用中に、暗号化された通信（HTTPS）で随時送信
目的アプリの利用統計の分析
保存期間3. の利用統計と同じ
関連ポリシーGoogle プライバシーポリシー、Firebase のプライバシーとセキュリティ

本アプリには統計の収集だけをオフにする設定はありません。移転を望まない場合は、本アプリの使用をやめて削除してください。削除後は送信されません。

6. 端末のアクセス許可

本アプリは次の許可を求めますが、すべて任意です。許可しなくても、駅を手動で選んでルート案内を使えます。許可はいつでも iPhone の設定で変更できます。

許可用途
位置情報（このAppの使用中）最寄り駅の検索、乗車中の現在位置の推定
カメラホームの案内板や電車の行先表示から乗る方向を確認
マイク、音声認識車内アナウンスから現在駅と開くドアの側を認識（端末内で処理）
モーションとフィットネス加速度センサーで電車の発車・停車を検知

7. 削除の方法

端末内の情報は、本アプリを削除すると iOS によって削除されます。利用統計は 3. の保存期間を過ぎると Google によって自動的に削除されます。開発者が情報を別途保管することはありません。

8. あなたの権利

  • 位置情報、カメラ、マイク、音声認識、モーションへのアクセスは、iPhone の設定でいつでも取り消せます。
  • 本アプリを削除すると端末内の情報はすべて消え、再インストールすると新しいアプリインスタンス ID が作られます。
  • 開示、訂正、削除、利用停止をご希望の場合は、下記のメールアドレスまでご連絡ください。速やかに対応します。ただし開発者はあなたを特定できる情報を持っていないため、特定の方の統計データを探し出せない場合があります。
  • 法定代理人や委任を受けた代理人を通じて権利を行使することもできます。

9. Cookie などの技術

本アプリはウェブの Cookie を使用しません。Google Analytics for Firebase は 1-c のアプリインスタンス ID で利用統計を区別します。望まない場合は本アプリを削除してください。

10. 安全管理

  • 必要最小限の情報だけを扱い、センシティブな処理はすべて端末内で行います。
  • 外部との通信はすべて暗号化された HTTPS で行います。
  • 開発者はサーバーやデータベースを持たないため、開発者側に利用者の情報が蓄積されることはありません。

11. お子様の情報

本アプリは13歳未満（韓国では14歳未満）のお子様を対象としておらず、お子様の個人情報を意図的に収集することはありません。
