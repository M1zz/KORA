乗る方向から降りる駅まで、1画面で

KORA は、韓国を旅するすべての人のための地下鉄ガイドアプリです。 出発駅と到着駅を選ぶだけで、乗り換え、駅数、所要時間の目安、そしてどちら方面の電車に乗ればいいかを、 電車の行先表示「○○行き」そのままの形で案内します。 乗車中は今どの駅かを追いかけ、降りるタイミングでお知らせします。

主な機能

出発駅はおまかせ

GPS で最寄り駅を探すか、自分で選べます。選んだ駅は次にアプリを開いたときも覚えています。

ルートと乗る方向

乗り換え、駅数、所要時間の目安に加えて、乗るべき電車を「○○行き」の表示で示します。終電が近いときは事前にお知らせします。

カメラで方向チェック

ホームの案内板や電車の行先表示にカメラを向けると、正しい方向かどうかを判定します。文字認識はすべて iPhone の中で行います。

今どこにいるか

ソウルのリアルタイム到着情報、GPS、加速度センサー（発車・停車の検知）、車内アナウンスの端末内認識を組み合わせて現在の駅を追跡します。アナウンスから、どちら側のドアが開くかもお知らせします。

降車のお知らせ

降りる駅が近づくと「そろそろ降車の準備」、到着すると「今降りてください!」を振動でお知らせします。路線の進行図には電車アイコンと到着駅のピンが表示されます。

ロック画面と Dynamic Island

乗車中はライブアクティビティで、iPhone を開かなくても進み具合を確認できます。

5つの言語

駅名を韓国語、日本語（カタカナ）、英語、中国語で並べて表示します。アプリ全体は 한국어・日本語・English・简体中文・繁體中文 から選べて、最初は iPhone の言語設定に合わせます。

オフラインでルート検索

ルートは端末内で計算するので、インターネットがなくても検索できます。ネットワークを使うのはリアルタイム到着情報だけです。

対応エリア

ソウル首都圏（ソウル・京畿・仁川。GTX-A、空港鉄道、新盆唐線、軽電鉄を含む）、釜山、大邱、光州、大田の 約930駅に対応しています。駅選択画面の上にある地域チップで都市を切り替えられます。

プライバシーを大切に

アカウント登録、広告、アプリ内課金はなく、開発者が運営するサーバーもありません。 位置情報、カメラ、アナウンス認識はすべて端末内で処理し、保存も送信もしません。 アプリ改善のために匿名の利用統計だけを収集しています。詳しくはプライバシーポリシーをご覧ください。
